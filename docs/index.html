Built around the grocery essentials

A focused Android demo covering the key shopping journey from browsing to order tracking.

🛍️

Browse and discover

Search the sample catalog, filter categories, and open detailed product pages.

🧺

Cart and checkout

Adjust item quantities, review a bill summary, and get an empty-cart prompt before checkout.

📍

Delivery addresses

Add, select, edit, and remove saved addresses from the account area.

📦

Orders and tracking

Review demo orders, item details, delivery address, and sample packing statuses.

📶

Works offline

The bundled sample catalog and locally saved cart remain available without internet access.

🔔

Device notifications

See on-device notifications for order confirmation and a sample grocery promotion.

Prototype note: This project uses local demo data. Order statuses and notifications are demonstrated on-device; it is not connected to a live store, delivery service, or payment system.

About the project

QuickBasket was developed as an Android internship project. The source repository includes the Java app and Gradle wrapper.
